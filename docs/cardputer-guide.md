# M5Stack Cardputer / CoreS3 Guide

## Pre-built binaries
Generated by GitHub Actions workflow **Build Embedded Binaries**:
- `mr-wiggles-cardputer-merged.bin`
- `mr-wiggles-cores3-merged.bin`

## Flash in <5 minutes

```bash
pip install esptool

# Cardputer
esptool.py --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash -z 0x0 mr-wiggles-cardputer-merged.bin

# CoreS3
esptool.py --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash -z 0x0 mr-wiggles-cores3-merged.bin
```

## UI and controls
- Radar view: real-time compact signal plot
- List view: channel/SSID/RSSI list
- Settings view: mode + scan controls
- Cardputer buttons A/B/C: navigate
- CoreS3 touchscreen: swipe/tap navigation

## Demo mode
Demo mode is built-in and enabled by default after boot, so the firmware is self-contained without external WiFi.
